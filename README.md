## 🚀 Current Project

### [LaneLens](https://github.com/Braoux/LaneLens)

LaneLens is a small League of Legends botlane matchup analyzer.

The idea is simple:

> Given four champions, what should you actually do in lane?

The project currently includes:

- matchup analysis
- level 1 / 2 / 3 guidance
- wave management advice
- trade windows
- target priority
- post-6 adjustments
- local history
- tester feedback
- AI provider abstraction
- runtime validation
- gameplay guardrails
- CI and production deployment

**Stack**

`TypeScript` · `Vite` · `Node.js` · `Hono` · `Riot Data Dragon` · `GitHub Actions` · `Render`

🔗 [Repository](https://github.com/Braoux/LaneLens)  
🌐 [Live Alpha](https://lanelens.onrender.com)
