## 🚀 Building BotDiff

<div align="center">

### ⚔️ [BotDiff — botlane matchup companion](https://github.com/Braoux/BotDiff)

**Four champions. One matchup. A clearer lane plan.**

[**Explore the public project**](https://github.com/Braoux/BotDiff) · [**Try the alpha**](https://lanelens.onrender.com/)

</div>

BotDiff helps League of Legends players prepare a specific 2v2 botlane: early-level decisions, trade opportunities, wave management, threats and target priority.

The product is currently in alpha. **The GitHub link above is its public showcase; the application source and development repository are private.**
